# 实验记录规范

之后每做一组实验，必须同时满足：

1. **完整设置**：超参、数据规模、seed、设备写入 `experiments/records/*.json`
2. **多次重复**：默认 **5 seeds**，汇报 **均值 ± 标准差**
3. **复杂度**：理论见 `experiments/复杂度分析.md`；实测耗时/峰值显存写入 JSON 并由汇总脚本统计
4. **产物命名**：`checkpoints/<dataset>_seed<seed>_best_model.pt`

## 单次运行

```bash
conda activate zpp1
python -u train.py --dataset yelp2018 --seed 1024 --epochs 25
```

## 多 seed 批跑

```bash
bash run_multi_seed.sh                 # 四数据集
bash run_multi_seed.sh yelp2018 douban # 指定数据集
```

## 仅汇总已有记录

```bash
python -u scripts/aggregate_results.py --all
```

## 记录字段说明

| 字段 | 含义 |
|------|------|
| settings | 全部超参与数据规模 |
| best_metrics | 最优 epoch 的 Top10/Top20 |
| epoch_logs | 每轮 loss 与指标 |
| wall_time_sec | 墙钟时间（秒） |
| peak_vram_mb | 峰值显存（MB） |
| param_count | 各模块参数量 |
