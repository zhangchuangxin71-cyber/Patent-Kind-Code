# CausalDiffRec 实验复现说明

## 1. 环境

- Python 环境：conda `zpp1`
- 主要依赖：torch 2.1.1+cu118、dgl 2.1.0+cu118、torch_geometric 2.5.3
- 硬件：NVIDIA GeForce RTX 4090（24GB）
- 运行入口：`python -u train.py --dataset <name> --epochs 25`
- 一键脚本：`bash run_all_experiments.sh`

支持数据集：`yelp2018`、`douban`、`food`、`kuairec`

## 2. 数据

| 数据集 | 来源 | 用户数 | 物品数 | 说明 |
|--------|------|--------|--------|------|
| Yelp2018 | 官方仓库 bin | 8093 | 13879 | popularity shift OOD 测试 |
| Douban | 官方仓库 bin | 8735 | 13143 | popularity shift OOD 测试 |
| Food | 本地 DRGO 预处理 bin | 7732 | 6293 | 与论文统计接近（论文 7809/6309） |
| KuaiRec | 本地 DRGO 预处理 bin | 7173 | 8775 | 物品数少于论文（论文 10611） |

数据路径：`dataset/<name>/`

## 3. 相对官方代码的必要改动

官方开源实现在 24GB 显存上无法直接跑通（`Graph_Editer` 的 `[K,n,n]` 约 7.7GB，叠加稠密邻接与随机稠密化噪声易 OOM）。复现时采用：

1. **低秩环境生成器**：`B_k ≈ U_k V_k^T`（rank=128），语义对齐已验证可跑通的 GPU 复现实现
2. **推荐阶段**：BPR batch_size=1024；梯度裁剪作用于 `rec_model`
3. **结果保存**：最优权重写入 `checkpoints/<dataset>_best_model.pt`；指标写入 `logs/<dataset>_final_result.txt`

默认超参与官方一致：epochs=25，hidden=8，emd_size=8，diffusion steps=100，seed=1024。

## 5. 结果解读

- **Yelp2018 / Douban**：官方数据 + 可跑通配置，指标达到并超过论文 Ours，主实验可认为复现成功。
- **Food**：本地预处理规模接近论文，Recall/NDCG 均不低于论文。
- **KuaiRec**：NDCG 明显低于论文。主要原因是本地 bin 物品规模（8775）与论文（10611）不一致，且曝光偏移划分可能与论文 Appendix C 不完全相同；Recall 量级仍可用，但不宜直接宣称完全对齐论文数字。

## 8. 多随机种子与记录规范（必须）

之后所有正式实验遵守：

1. **每组实验写完整设置与结果** → `experiments/records/<dataset>_seed<seed>.json`
2. **默认 5 个 seed** `{1024,2048,3072,4096,5120}`，汇报 **均值 ± 标准差**
3. **复杂度** → `experiments/复杂度分析.md` + 实测 `wall_time_sec` / `peak_vram_mb`
4. **汇总表** → `experiments/实验记录总表.md`（由 `scripts/aggregate_results.py` 刷新）

```bash
bash run_multi_seed.sh
python -u scripts/aggregate_results.py --all
```
